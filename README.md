# CALCULADORA CIENTÍFICA

## Descripción

Proyecto de una calculadora científica desarrollada en Python por estudiantes de la FNI, de las carreras de Ingeniería de Sistemas e Ingeniería Informática.

El código está en el archivo `calculadora.py` y se irá ampliando con nuevas funciones.

## Operaciones

Actualmente el archivo `calculadora.py` contiene las siguientes funciones:

- **Suma**: `suma(a, b)`
- **Resta**: `resta(a, b)`
- **Multiplicación**: `multiplicacion(a, b)`

```python
def suma(a, b):
    return a + b

def resta(a, b):
    return a - b

def multiplicacion(a, b):
    return a * b
```

_Se agregarán más funciones próximamente._

## Ejecución

1. Abrir una terminal en la carpeta del proyecto.
2. Ejecutar el programa:

```bash
python calculadora.py
```

3. Seleccionar la operación.
4. Introducir los valores.
5. Obtener el resultado.
